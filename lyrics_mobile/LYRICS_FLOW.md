# 2026-11-03 동의 기반 가사 탐색·생성

## 최신 후속 변경

아래는 초기 구현 기록입니다. 현재는 가사 조회 실패(503 포함) 후 **명시적 동의 → 선택한 AI에 가사 직접 요청** 경로가 추가되었습니다. 기존 곡 정보 보정 경로와 별개이며 웹 검색/출처 검증은 하지 않습니다. 비용·거절 가능성·정확도 한계를 팝업에 알리고, 결과는 AI 응답·미검증으로 표시하여 별도 `ai_lyrics` 캐시에 저장합니다. 같은 곡/제공자/모델로 동의 후 재요청 시 저장본을 재사용합니다. 실패·잘못된 형식은 저장하지 않고 싱크 시간도 생성하지 않습니다. 번역/발음 자동 생성 없음. Better Lyrics/LRC Mux 및 자동 스크롤은 조사만 완료했으며 아직 연동하지 않았습니다. 상세 조사 내용은 PROJECT_NOTES.md 후속 항목을 참조하세요.

## 적용한 흐름

1. 곡을 열면 저장된 원문 또는 LRCLIB를 조회한다.
2. NOT_FOUND인 경우만 보수적인 곡 정보 정리와 카탈로그 검증 후 원문 재조회를 시도한다. 제목/가수/재생 길이와 버전이 맞아야 하며, 서로 다른 판본이 여러 개면 임의로 고르지 않는다.
3. 보조 정식 제공처 연결 지점을 확인한다. 현재 계정·계약·접근 키가 없어 기본 구현은 미연결이며 외부 조회를 하지 않는다.
4. 여전히 NOT_FOUND이면 'AI로 가사를 추가 탐색할까요?'를 표시한다. 취소는 AI를 호출하지 않는다.
5. 동의하면 선택한 제공자/모델/첫 번째 키로 곡 정보 보정을 요청한다. AI 출력 중 제목/가수만 사용하며 가사·URL 필드는 사용하지 않는다. 결과를 실제 카탈로그로 검증한 뒤 LRCLIB 원문만 가져온다.
6. 성공 원문은 출처와 함께 저장한다. 번역·발음은 별도 선택 전 생성하지 않는다.

네트워크 오류, 429, 503은 가사 없음으로 바꾸지 않으며 자동 유료 AI 탐색으로 넘기지 않는다. AI 메타데이터 요청은 키 순환이나 다른 제공자로 자동 재요청하지 않는다. 번역의 기존 GPT 우선/Gemini 조건부 대체 정책과는 별개다.

## 유료 생성 조건

- 기본값: 함께 보기를 열거나 화면을 회전해도 새 번역/발음 생성 없음.
- 상세창 열기: 현재 제공자·모델·언어·원문에 맞는 캐시만 디스크에서 미리 읽는다. 캐시 미스는 AI 요청으로 이어지지 않는다.
- 번역/발음 탭 또는 '만들기 · API 사용'을 선택하면 해당 기능만 생성한다. 원문을 기다리는 중 선택하면 원문 확보 후 처리한다.
- 함께 보기 설정은 표시 항목일 뿐 생성 동의가 아니다.
- 읽기 설정의 '선택한 번역·발음 미리 생성 (API 사용료 발생)'은 기본 꺼짐이며 켠 경우에만 자동 생성한다.
- 동의형 AI 가사 복구 성공 후에는 미리 생성 옵션과 관계없이 번역·발음을 별도 선택하게 한다.
- HTTP 클라이언트를 재사용해 연결 풀을 유지한다. 사전 유료 키 테스트·빈 생성·웹 검색 요청은 하지 않는다. 모델 서버의 생성 시간을 없애는 기능은 아니다.
- 원문을 직접 붙여넣을 수 있다. 사용자 입력 출처를 표시하고 저장한다. 파일 가져오기는 아직 구현하지 않았다.

## 아직 연결되지 않은 부분

- 보조 정식 가사 제공처: `LyricsRecovery.OfficialProvider` 인터페이스와 순서만 준비. 실제 Musixmatch 등의 계정/이용 권한/표시·저장 조건을 확보해야 실제 어댑터를 연결할 수 있다. 미연결을 조회 성공이나 '가사 없음'으로 가장하지 않는다.
- 최종 AI: 현재는 곡 정보 보정과 검증된 LRCLIB 재탐색이다. 웹 전체 검색 도구나 다른 사이트의 가사 수집 기능은 없다. 팝업에도 이 범위를 명시한다. AI가 생성한 가사를 원본으로 표시하지 않는다.
- AI 보정은 다른 가수로 변경할 수 없고, 길이 정보가 없거나 다른 판본이 섞이면 중단한다. 이 보수적 조건 때문에 같은 곡이라도 복구되지 않을 수 있다.
- 모델이 같은 제목·가수를 그대로 반환하면 반복 조회하지 않는다. 명시적 재시도는 다시 사용량을 소모할 수 있다.
- 실제 유료 API 호출과 제공처 계약 계정은 사용하지 않았다. 가짜 클라이언트로 동의 전 호출 차단을 검증한다.

## 적용한 개발 프롬프트 기준

기존 기능을 보존하고, 표시 설정과 유료 실행 동의를 분리한다. 캐시와 출처 정보를 먼저 준비하되 몰래 생성하지 않는다. 검색·가사 조회·번역 실패를 각각 구분한다. 확인되지 않은 곡이나 AI 추측을 원문으로 표시하지 않는다. 사용자가 결과를 선택·승인하기 전에는 비용이 발생하는 작업을 시작하지 않는다. 가사창은 단일 스크롤 영역으로 유지하며 이전 창의 지연된 닫힘 콜백이 새 창을 종료하지 않도록 한다. 디자인은 시안 확인 후 적용하며, 이번 피드백을 반영해 독서 앱보다 음악 앱의 색·아트 중심 표현을 우선한다.
